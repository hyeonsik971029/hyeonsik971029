## 👨‍💻 About Me

안녕하세요. iOS 개발자인 오현식입니다. 효과적인 코드 유지보수를 위해 아키텍처 설계를 고민하고 적용하는 것을 중요하게 생각합니다.

ReactorKit을 활용하여 사내 프로젝트(커피 배달 서비스)와 개인 프로젝트(SOOUM)의 상태 관리와 비즈니스 로직을 분리했으며, 개인 프로젝트에서는 TCA(The Composable Architecture)를 도입해 모듈화된 구조와 단방향 데이터 흐름을 구현했습니다.
두 아키텍처 패턴을 실제 프로젝트에 적용하며 코드의 예측 가능성과 테스트가 쉬운 코드를 작성했습니다.
